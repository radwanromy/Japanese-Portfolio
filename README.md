# Japanese Portfolio — A.S.M. Radwan

Personal portfolio site built for my BJET (Japan software engineer training program) application, and used as my general professional portfolio in Japan.

**Live site:** https://radwanromy.github.io/Japanese-Portfolio/

## Overview

A responsive, dark/light-theme portfolio in Japanese, covering:

- About / experience summary
- Frontend & backend skills (TypeScript, React, Spring Boot, Django, etc.)
- Featured projects with links
- Client testimonials
- Contact form and direct contact links

## Tech Stack

HTML5 · CSS3 · JavaScript — Swiper.js (testimonial carousel), MixItUp (project filtering), ScrollReveal (scroll animations), Boxicons.

## Running locally

This is a static site — no build step required.

```bash
git clone https://github.com/radwanromy/Japanese-Portfolio.git
cd Japanese-Portfolio
# open index.html directly, or serve it:
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
